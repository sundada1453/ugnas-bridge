# F3-5 同步页四态 Diff 展示规格（实现依据）

> 来源：产品经理定稿 `prototype/README.md`「四态 diff 展示规则（F3，含 expired 态）」+ CEO 2026-10-30 验收补充
> 注意：`prototype/index.html` 当前是三态（新增/更新/无变化），**expired 第四态以本规格为准**，勿照抄原型漏项。

## 四态定义（按 onlyName + 端口双向匹配）

| 状态 | 标签样式 | 左侧色条 | 判定 | 默认勾选 | 处置 |
|---|---|---|---|---|---|
| 新增 new | 绿 tag green | 绿 | 发现结果未命中任何既有卡片 | ✅ | 建卡（分组/命名/图标按配置） |
| 更新 update | 琥珀 tag amber | 琥珀 | 命中但分组/命名/图标有差异 | ✅ | 更新差异项；lanUrl 默认不动 |
| 无变化 same | 灰 tag gray | 灰 | 命中且字段全一致 | ❌ | 仅展示，不可操作 |
| 过期 expired | 红 tag red + 「清理建议」角标 | 红 | 既有卡片未命中任何发现结果（含手动绑定池） | ❌（人工确认） | 跳过(默认)/移入「回收站」分组/删除(二次确认) |

## expired 展示与交互细则（架构师按此实现）

1. **角标**：行内右上红色小角标「清理建议」，hover 提示「该卡片未匹配到任何运行中应用（onlyName+端口 均未命中）」
2. **计数**：顶部统计条增加红色 `过期 N`；「执行同步」按钮文案只统计**勾选项**（如「执行同步（5 项）」），非固定 26
3. **批量清理**：列表顶部「仅选过期」快捷勾选，一次选中全部 expired
4. **安全阀**：删除类操作走二次确认弹窗（列出待删卡片名+端口）；state 快照覆盖过期清理，回滚可整批恢复
5. **显示顺序**：新增 → 更新 → 过期 → 无变化；无变化沉底折叠，可展开

## 实现落点

- 后端 `sunpanel/diff.py`：`DiffEngine.diff()` 返回 `state ∈ {new,update,same,expired}` + `reason`
- 后端 `service/sync_service.py`：`plan()` 仅对勾选项生成操作；expired 的 `dispose ∈ {skip,trash,delete}`
- 前端：标签/色条/角标/计数/排序/折叠按上表；删除二次确认；「仅选过期」按钮
