# 部署手册 · ugnas-bridge

四种位置任选其一，只改参数，代码不动。

---

## 0. 参数总表

| 参数 | 含义 | 默认 | 说明 |
|---|---|---|---|
| `BIND` | 监听地址 | `0.0.0.0` | 只给本机用可改 `127.0.0.1` |
| `PORT` | 服务端口 | `8770` | 卡片 url 会写 `http://<地址>:<PORT>/open/<port>` |
| `SERVICE_HOST` | 卡片里用的可达地址 | 必填 | 局域网用内网 IP；公网用域名/IP |
| `DEST` | 安装目录 | `/opt/ugnas-bridge` | |
| `RUN_USER` | 运行用户 | `root` | 建议非 root 低权用户 |
| `LOGDIR` | 日志目录 | `/var/log/ugnas-bridge` | `bridge.log` 为心跳+访问日志 |
| `UGNAS_BRIDGE_REFRESH` | token 续期周期(秒) | `1800` | |
| `UGNAS_BRIDGE_HEARTBEAT` | 心跳日志周期(秒) | `300` | 常驻可见证据 |
| `UGNAS_BRIDGE_USER` / `UGNAS_BRIDGE_PASS` | UGOS 登录凭据 | 必填 | 只进 `/etc/ugnas-bridge.env`（0600） |
| `UGNAS_BRIDGE_KEY` | /open/* 访问口令 | 自动生成 32 位 | 公网部署必开 |

## 1. 通用安装（三行）

```bash
cd /path/to/ugnas-bridge/deploy
sudo UGNAS_BRIDGE_PASS='<UGOS密码>' ./install.sh --host 0.0.0.0 --port 8770
```

安装后自检：
```bash
systemctl --no-pager status ugnas-bridge
curl -sS http://127.0.0.1:8770/health
tail -f /var/log/ugnas-bridge/bridge.log
```
`HEARTBEAT {...}` 每 300s 一行，即“常驻任务可见证据”。

卸载：`sudo ./install.sh --uninstall`

## 2. 四种部署位置

### 2.1 本机（开发机）
只覆盖同网段。`SERVICE_HOST=<本机IP>`。

### 2.2 软路由（OpenWrt / iStoreOS）
前提：`opkg install python3`。无 systemd 用 procd/crontab 守护：
```sh
#!/bin/sh /etc/rc.common
START=99
start() {
  UGNAS_BRIDGE_PASS="<密码>" UGNAS_BRIDGE_PORT=8770 nohup python3 /opt/ugnas-bridge/poc/ugnas_bridge.py \
     >>/var/log/ugnas-bridge/bridge.log 2>&1 &
}
stop() { pkill -f ugnas_bridge.py; }
```

### 2.3 NAS 上（局域网全覆盖）
前提：NAS 能跑 python3，不新建 Docker，直接宿主进程：
```bash
rsync -a ugnas-bridge/ <user>@<NAS_IP>:/opt/ugnas-bridge/
ssh <user>@<NAS_IP> 'sudo UGNAS_BRIDGE_PASS=... /opt/ugnas-bridge/deploy/install.sh --port 8770'
```

### 2.4 公网云主机（全场景可用，v1 选用）
已部署：`/opt/ugnas-bridge`，systemd `ugnas-bridge.service`（enabled + active），监听 `0.0.0.0:8770`。
- 访问口令：`sudo cat /etc/ugnas-bridge.env` 里的 `UGNAS_BRIDGE_KEY`（32 位，0600）
- 每次请求形如 `http://<SERVICE_IP>:8770/open/8080?k=<口令>`
- 云厂商安全组放行入站 TCP 8770 + 主机防火墙 `ufw allow 8770/tcp`

---

## 3. 改端口 / 改地址

```bash
sudo sed -i 's/^Environment=UGNAS_BRIDGE_PORT=.*/Environment=UGNAS_BRIDGE_PORT=8771/' /etc/systemd/system/ugnas-bridge.service
sudo systemctl daemon-reload && sudo systemctl restart ugnas-bridge
```
卡片 url 同步重跑 `tools/update_cards.py --service-base http://<SERVICE_HOST>:<PORT> --apply`。

## 4. 验收清单

- [ ] `systemctl is-enabled ugnas-bridge` = enabled
- [ ] `/health` 返回 `ok:true`
- [ ] `bridge.log` 有 HEARTBEAT 行
- [ ] 手机访问 `/open/8080?k=<KEY>` → 进 Sub2API 首页（无绿联登录框）
- [ ] `/open/5244` → 到 OpenList 自己的登录页（UGOS 层已免登录＝达标）

## 6. 附录 B：已知限制

1. 部分机房/运营商网络对非常用端口的明文 HTTP 有干扰（TCP 通、数据包丢），换网络或加 TLS 即可；家用宽带/手机流量不受影响。
2. Sun-Panel 1.8.1 无 `item/batchUpdate`（需 ≥2.0.0-dev-13），脚本自动降级逐条 `item/update`。
3. OpenList / Emby 等应用自身有账号体系，UGOS 层免登录后仍会看到应用登录页，属预期。
4. redirect_url 为一次性，刷新页面会重新走 `/open/<port>` 生成新的一次性地址。
